\# CSA1611 — Data Warehousing and Data Mining



\*\*Saveetha School of Engineering\*\*



\## About the Course



This repository is dedicated to the practical learning of \*\*Data Warehousing and Data Mining (DWDM)\*\* using RStudio and WEKA. It provides a foundation in statistical computing, data preprocessing, data analysis, and data mining techniques.



\## Tools and Technologies



\### R and RStudio



R is a programming language used for statistical computing, data analysis, and visualization. RStudio is an integrated development environment (IDE) that provides tools to write, execute, debug, and manage R programs efficiently.



\*\*Key Applications\*\*

\- Statistical analysis and descriptive statistics

\- Data preprocessing and normalization

\- Data smoothing and binning

\- Data visualization and graphical analysis

\- Exploratory data analysis



Official resources: \[R Project](https://www.r-project.org/) · \[RStudio Desktop](https://posit.co/download/rstudio-desktop/)



\### WEKA



WEKA (Waikato Environment for Knowledge Analysis) is an open-source software suite for machine learning and data mining. It provides a graphical interface for processing datasets, applying algorithms, and evaluating analytical models.



\*\*Key Applications\*\*

\- Data preprocessing and attribute selection

\- Classification and regression

\- Clustering

\- Association rule mining

\- Machine learning model evaluation



Official resource: \[WEKA](https://www.cs.waikato.ac.nz/ml/weka/)
